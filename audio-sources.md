# SmartIPA audio references

Looked up on 2026-10-11. Every clip is hosted on Wikimedia Commons and is the one English Wikipedia plays for that symbol (mapping taken from [Module:IPA symbol/data](https://en.wikipedia.org/wiki/Module:IPA_symbol/data)). File, licence and author were read from the Commons API for each file. Nothing has been downloaded yet.

- 121 sounds, 121 clips found, about 3.8 MB in total.
- Licences: 107 CC BY-SA 3.0, 8 CC BY-SA 4.0, 3 CC0, 2 public domain, 1 CC BY 2.5.
- "—" in the author column means Commons has no machine-readable author for that file; the author is named on the file page and must be copied from there for the credits.
- Each link opens the Commons file page, where the clip can be played and the licence checked.
